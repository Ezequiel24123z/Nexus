# Status & Roadmap (`v1.5.0` Standalone Native Release)

Updated: November 28, 2026.

## Implemented in NEXUS `v1.5.0`

- **NEXUS App Self-Edit Protection, Full Self-Control (`nexus_control`) & Single-UAC Persistent Admin Worker (`core/nexus-control.mjs`, `core/runtime.mjs`, `core/coding-engine.mjs`)**:
  - Hard runtime guardrail (`detectNexusSelfModification`) requiring explicit one-time user confirmation before modifying NEXUS installation/source files, internal state (`workspace.json`, `nexus.config.json`, `vault.*`), or stopping/restarting `NEXUS.exe` — enforced **even in Unrestricted mode** and immune to "Always Allow" / session auto-approve.
  - Default cwd for workspace-less chats safely falls back away from the NEXUS install directory.
  - New `nexus_control` core tool gives AI complete live feature documentation (`guide`), secret-safe full config/state introspection (`inspect`), and live control over settings, session modes, custom providers, per-provider enabled models, and tools without inspecting NEXUS source code.
  - Persistent single-UAC `ElevatedAdminBroker` (authenticated `127.0.0.1` loopback worker spawning elevated child processes with cancel support) eliminates repeated Windows UAC prompts across commands in Admin-enabled sessions.
- **Native Yeta Labs Provider, Strict Active-Provider / Enabled-Models Picker, Proactive Session Renaming, Clearer Sidebar Status, Copilot-Style Activity Feed & Core Efficiency**:
  - Native first-class **Yeta Labs** provider (`yeta/`, live `/v1/models`, vision metadata, per-model `reasoning_effort` normalization) + safe raster `data:image/*` rendering in `MarkdownRenderer`.
  - Model Picker (`ModelPickerPopover.jsx`), Settings, Automations, and Arena strictly scope models to the currently selected provider and its per-provider `enabledModels` list (preventing OpenRouter catalog bleed-through) with inline **Enabled** model curation.
  - Proactive session renaming directives at Turn 1 and on topic/objective shifts (even when `globalInstructions` is customized) with parallel turn-1 rename execution.
  - Upgraded left sidebar with distinct live/finished icons (`Loader2` spinner, `CheckCircle2`, `ShieldAlert`, `Clock`, `PauseCircle`, `AlertCircle`), status pills (`Live`/`Done`/`Approve`/`Paused`/`Error`), left accent rails, live count badge, and `All / Active / Done` filter strip.
  - GitHub Copilot-style flat chronological activity feed (`ToolTimeline.jsx`, `ChatView.jsx`): borderless clickable rows (`Thought for 18s`, `View file`, `Edit file +N -N`, `>_ Run command` with inline preview, clean formatted output/diff drawers), real `reasoningDurationMs` tracking, and core efficiency optimizations (compact `workspace.json` events/effects keeping `journal.jsonl` lossless, 5s TTL workspace metadata cache, single-pass context estimation, and consecutive-failure thrashing nudge).
  - Expanded `manage_privacy` with `verify` (live IP/VPN/proxy check), `apply_preset` (1-step privacy setup), `wireguard_select`/`remove`/`install`, `tor_install`, `wipe_browser`, and misconfiguration warnings; PII Scrubber restores local display paths for the user while keeping all outbound cloud payloads redacted.

## Implemented in NEXUS `v1.4.0`
- **App-Scoped WireGuard VPN (`wireproxy`) & Double-Hop WireGuard → Tor (`core/wireguard-manager.mjs`, `core/tor-manager.mjs`)**: Zero-admin user-space WireGuard client (`127.0.0.1:9060`, Mullvad/IVPN/Proton/AirVPN `.conf` import encrypted in DPAPI vault) + `wireguard-tor` double-hop chaining so your ISP never sees Tor and the VPN never sees destinations.
- **Reversible Outbound PII & Path Scrubber + Cache-Preserving 1-Click Stealth Mode (`core/pii-scrubber.mjs`)**: Redacts `C:\Users\<name>`, PC hostname, and custom sensitive strings from cloud LLM prompts (restored transparently on local tool execution), paired with 1-Click Stealth Mode that **preserves `promptCaching` and `cacheAffinity`**.
- **Bidirectional RAM-Only ↔ Regular Sessions (`core/store.mjs`, `core/artifacts.mjs`, `manage_session`, `spawn_session`)**: Create RAM-Only zero-disk-trace sessions or nested sub-sessions, and live-migrate Regular ↔ RAM-Only anytime (purging disk traces immediately or materializing to disk on demand) either by user click or autonomously by the AI.
- **Per-Session Windows Administrator Rights (`core/coding-engine.mjs`, `native-host/Program.cs`, `ChatView.jsx`)**: Grant elevated Windows Admin privileges per session for VPN/services/firewall tasks via UAC or process elevation + 1-click **Restart as Admin** in Settings.
- **Inline Chat Documents, Images, Audio & Streaming Video Viewer (`present_media`, `ChatMediaCard.jsx`, `/api/media/:id`)**: Core tool and Range-streaming (`206 Partial Content`) inline cards for images (with Lightbox), HTML5 videos, audio, embedded PDFs, Markdown, CSV tables, and code documents.

## Implemented in NEXUS `v1.3.0`

- **App-Wide Tor / SOCKS5h Encryption, Streaming & Fail-Closed Kill-Switch (`core/privacy-proxy.mjs`)**: True `ReadableStream` SSE over Tor/SOCKS5h, unified `createNexusFetcher` for all outbound traffic (LLM APIs, search, browser, MCP, skills, updates) with remote DNS resolution, hard `.onion` clearnet block, `torStrictFailClosed` kill-switch, and live **0–100 Anonymity & OPSEC Scorecard**.
- **Multi-Tier Private, AI & Tor `.onion` Search Suite (`core/search-engines.mjs`)**: 13 configurable modes (Auto Privacy-First, SearXNG, DuckDuckGo, Mojeek, Brave ZDR, Kagi, LangSearch, Tavily, Exa, Ahmia, Torch `.onion` strictly via Tor, Combined `.onion`, optional Bing RSS blocked under Strict Zero-Track) + DPAPI vault secret keys in Settings.
- **Dual-Mode Specialized Agent Browser (`core/agent-browser.mjs` + `NativeBrowser.cs` + `PrivateBrowserView.jsx` + `BrowserSidePanel.jsx`)**: Fast zero-bloat `@e1..@eN` accessibility snapshot & Markdown engine (`agent-fast`) alongside live DOM-ref WebView2 JS (`agent-js` with tracker/media blocking & `press_key`) and the standard visual browser.
- **GitHub Auto-Updater, Custom System Prompt Protection & Visual Changelog (`core/updater.mjs` + `core/changelog.mjs` + `ChangelogView.jsx`)**: Interactive vertical release timeline with filters/search, SHA-256 verified portable updates, pre-update prompt/config backups, and permanent protection for user-edited system prompts (`globalInstructionsCustomized` + always-preserved `customSystemPrompt` addendum).
- **AI Project & Session Self-Management (`manage_project` + `manage_session`)**: Core tools enabling agents to create/update projects, assign sessions to projects, rename sessions, set workspaces, and pin threads.

## Implemented in NEXUS `v1.2.0`

- **Structured User Memory, Priorities & Working Style System (`core/memory.mjs` + `MemoryView.jsx`)**:
  - Dedicated **Memory & Profile** view in the sidebar & Command Palette with 6 categories (`priority`, `preference`, `constraint`, `workflow`, `profile`, `fact`), 4 priority levels (`critical`, `high`, `normal`, `low`), pinning, tags, Global vs. Project scopes, live **Prompt Preview**, and Markdown/JSON export & import.
  - Priority-ranked Markdown context injection into `runtime.buildContext()` and upgraded `memory_store` (`list`, `search`, `remember`, `update`, `forget`, `profile`) promoted into `CORE_TOOL_NAMES` so user preferences and priorities are always respected across sessions.
- **Native Headless Edge WebView2 JS Rendering & DOM Automation (`NativeBrowser.cs`)**:
  - `browser_inspect` now wires directly to `NEXUS.exe --browser-inspect`, executing real JavaScript for SPAs (`renderJs: true`, `waitMs`, `waitForSelector`), running scripted DOM `actions` (`click`, `type`, `select`, `scroll`, `wait`, `eval`), optionally reusing Account Mode cookies, returning interactive CSS selectors, and capturing screenshots while preserving full extracted DOM text.
  - Semi-Autopilot gates interactive/account browser actions while passive reads remain frictionless.
- **Windows UI Automation, Privacy-Safe Window Capture & Multi-Monitor Support (`NativeDesktop.cs` + `ui-tree.ps1`)**:
  - `desktop_windows` (`--list-windows`) enumerates all monitors and visible windows; `desktop_ui_tree` inspects the real Windows UI Automation accessibility tree returning buttons, inputs, values, and exact click centers with zero screenshots; `desktop_screenshot` supports window-only capture (`PrintWindow`), multi-monitor (`0`, `1`, `"all"`), and region crops; `desktop_action` adds `focus_window`, `move`, and `drag`.
- **Realistic Configurable Browser HTTP Headers**:
  - Standard Edge/Chrome Windows browser headers across `web_fetch`, `browser_inspect`, and `web_search` (no longer exposing `NEXUS-Agent`), with optional custom `webUserAgent` override in Settings and `nexus.config.json`.

## Implemented in NEXUS `v1.1.0`

- **True Standalone Native Windows App (Zero Electron)**: Native C# / .NET 10 + `Microsoft.Web.WebView2` host (`NEXUS.exe`) with Win11 Dark Titlebar, System Tray, `Ctrl+Shift+Space` global summon hotkey, crash watchdogs (`host.log`/`core.log`, WebView2 `ProcessFailed` auto-recovery, Core daemon auto-restart), native OS dialogs, and a single-folder portable bundler (`npm run dist:portable` → `release/NEXUS-Portable/`).
- **Zero-Flicker Streaming & Crash-Hardened Runtime**:
  - Lightweight SSE `delta` event stream (~1 KB/frame) decoupled from full workspace snapshots, grouped multi-step turns (`WorkStepsGroup`), block-memoized streaming Markdown with **Mermaid SVG** diagrams and **KaTeX** math, inline unified diffs with 1-click **Revert**, and Windows `EPERM`/`EBUSY`-safe debounced atomic saves + compacted OpenRouter router metadata.
- **4-Tier Autonomy Levels**: Replaced rigid functional modes with **Interactive**, **Semi-Autopilot** (auto-runs reads & safe workspace edits, prompts with exact reason on risky commands/deletions/push/external HTTP), **Autopilot**, and **Unrestricted**.
- **Copilot-Style Model Picker Popover**: Quick popover directly above the composer with **Model Restriction/Freedom Filters** (`Unrestricted`, `Minimal — DeepSeek/Grok`, `Low — GLM/Qwen/Llama`, `Moderate`, `Standard`), **Capability Filters** (`Frontier`, `Coding`, `Reasoning`, `Fast`, `Vision`, `200K+ Ctx`, `Budget/Free`), inline **Reasoning Level**, **Context Window**, **OpenRouter Routing** (`Auto`/`Cheapest`/`Fastest`/`Lowest Latency`) & upstream provider preference.
- **Integrated Private Browser (`PrivateBrowserView` + Native InPrivate WebView2)**: Dedicated InPrivate WebView2 browser profile with **Tor (SOCKS5 9050)**, **SOCKS5**, **HTTP Proxy**, **System VPN detection**, DNS/WebRTC leak protection, network tracker blocking, anti-fingerprinting, 1-click **Wipe**, **Send to AI**, and **Screenshot**.
- **Rooted Projects, Orchestrated Nested Sessions & Self-Evolution**:
  - Projects bound to root folders auto-discover `NEXUS.md`/`CLAUDE.md`/`AGENTS.md` and `.nexus/.github/.claude/skills/*/SKILL.md`.
  - Agents can orchestrate **concurrent Nested Child Sessions** (`spawn_session`, `list_sessions`, `send_session_message`, `read_session`) with indented Sidebar tree visualization, in-chat Parent/Child navigation, and automatic child completion handoff.
  - **Skills & Plugins Gallery** (`GalleryView`): 12 cloud-adapted Skills (from `obra/superpowers`, `anthropics/skills`, `github/awesome-copilot`), 4 zero-dependency **Hot-Loaded Native JS Plugins** (`SQLite Explorer`, `Network Diagnostics`, `Dev Crypto & JWT`, `Archive Pack`), 9 1-click **Cloud MCP Plugins**, direct GitHub `SKILL.md` URL importer, and live **Self-Evolution** via `create_dynamic_tool`.
- **Interactive Streaming Terminal & Local Automations**: Real native **Win32 ConPTY (`CreatePseudoConsole`)** pseudo-console in C# (`native-host/ConPtyHost.cs`, Zero Electron, zero `node-pty`) with Tab completion, arrow keys, Ctrl+C, and TUI support + local cron/interval/daily/weekly/one-shot Automations scheduler.
- **Wave 4 Performance, Caching & Compaction Overhaul**:
  - **Smart Lazy Toolsets (`load_toolset`)**: Cuts Step-1 input tokens by **65%** (`8,643 → 3,022 tok` verified live on OpenRouter DeepSeek V4.1 Flash) by starting with ~18 core tools and loading optional groups (`git`, `web_browser`, `sessions`, `capabilities_mcp`, `connectors`, `desktop`, `automations_evolve`, `plugins`) on demand.
  - **Explicit Prompt Caching & Telemetry**: Ephemeral `cache_control` breakpoints for Anthropic Direct and OpenRouter Claude/Gemini, `prompt_cache_key` on OpenAI Direct, and live `% cached` badge in chat footers & Context Inspector.
  - **2-Stage Lossless Compaction**: Fixed `compactionTail` empty-archive/tool-group boundaries & multimodal deduplication; added **Stage 1 Zero-Cost Micro-Compaction** (prunes old oversized tool outputs into lossless artifact references for `$0` before full LLM compaction); added `/compact`, **Micro-Prune ($0)**, **Compact Now** buttons, and automatic empty-tail retry for tight ceilings.
  - **Granular Semi-Autopilot Allow/Deny Rules & Nested Session Controls**: Editable allow/deny pattern rules (`tool:substring` or `/regex/i`) in Settings + 1-click **Always Allow** in approval banners + in-chat **+ Spawn Child** & **Send Message** modals.
  - **Live GitHub `SKILL.md` Cloud Search + MCP Test & Connect + Vite Code-Splitting + Chat Turn Windowing**: Real-time GitHub `SKILL.md` search in Gallery, 1-click MCP connect & live tool count test, Vite vendor chunk splitting (`index.js` ~444 KB / 121 KB gzip), and 40-turn progressive DOM windowing for 60 FPS long sessions.
- **Full Application Audit & Security Hardening (`v1.1.0`)**:
  - **Security Hardening**: Switched Mermaid rendering to `securityLevel: 'strict'` (blocks diagram XSS → RCE), eliminated `cmd.exe /c start` shell injection in `openWithShell`, migrated DPAPI vault encryption/decryption to `stdin` piping with 5-file backup rotation, enforced loopback-only CORS + constant-time token checks + workspace containment on file endpoints in `core/server.mjs`, sanitized `pluginId` in `PluginManager.createSingleTool`, validated WebView2 bridge origin (`e.Source`), restricted `NewWindowRequested`/`openExternal` to `http`/`https`, and validated browser proxy URIs against Chromium CLI flag injection.
  - **Runtime & UI Reliability**: Fixed React Rules-of-Hooks crash during streaming fenced code/Mermaid transitions (`MarkdownRenderer.jsx`), removed React updater side effect in `StudioView.jsx`, fixed `0` (midnight/Sunday) falsy coercion in `validateAutomation`, added `|| '{}'` fallback for parameterless tool calls in `runtime.mjs`, fixed Semi-Autopilot relative path traversal detection, fixed Tor `torrc` quoting for paths with spaces and unawaited timeout rejections, hardened SOCKS5 leftover-byte buffering and HTTP 204/304 responses in `privacy-proxy.mjs`, and added watchdog restart rate limiting + handle cleanup in `Program.cs`/`ConPtyHost.cs`.
  - **Zero-Electron Cleanup & Release Pipeline**: Removed 5 obsolete Electron smoke files, migrated all vault/live CLI scripts to pure Node 24 + `SecretVault`, translated remaining Spanish error messages/launcher (`Launch NEXUS.cmd`) to English, synchronized `1.1.0` across all manifests/endpoints/`NEXUS.csproj`, and fixed `build-portable.mjs` + `.github/workflows/desktop.yml` to package and publish `NEXUS-Portable-Windows.zip` with explicit `.NET 10` setup.
